## 四、美术资源替换 SOP

### 步骤 1：准备替换资源

1. 按照上方目录结构，将新资源放入 `assets/` 对应子目录
2. 文件名必须与占位文件名**完全一致**
3. 图片规格必须与占位规格一致（尺寸/格式/像素密度）

### 步骤 2：更新 Godot 资源引用

对于 **Texture2D (.png → .import)**：
```
1. 将新 png 覆盖 assets/ 下同名文件
2. Godot 编辑器会自动检测文件变更并重新导入
3. 所有引用该资源的节点自动更新显示
```

对于 **TileSet (.tres)**：
```
1. 在 Godot 编辑器中打开 TileMap 节点
2. 选择对应 TileSet 资源
3. 在 TileSet 底部面板中更换源纹理
4. 重新绘制碰撞体（如有变更）
```

对于 **PackedScene 内嵌精灵**：
```
1. 打开使用占位色块的场景文件 (.tscn)
2. 选中 Sprite2D 节点
3. 在 Inspector 中将 Texture 从占位色块替换为新资源
4. 保存场景
```

### 步骤 3：验证

```bash
# 运行游戏检查所有场景
godot bianjingyuanzheng/project.godot

# 检查清单:

# □ 怪物精灵在地图和战斗中均显示
# □ 物品图标在背包和锻造界面显示
# □ 图鉴复原图在战后揭秘中显示
# □ 天气粒子效果正常播放
# □ UI面板无拉伸变形
# □ 字体渲染正常无乱码
```

### 步骤 4：提交

```bash
git add assets/
git commit -m "assets: 替换 [具体资源名] 占位资源为正式美术"
```

### 约定

- 占位资源文件名以 `_placeholder` 结尾的，替换时去掉此后缀
- 一次 PR 只替换一个系统/场景的美术资源
- 替换后需在编辑器运行验证后再提交

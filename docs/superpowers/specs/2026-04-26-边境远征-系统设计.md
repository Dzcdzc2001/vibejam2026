## 1. 场景架构与模块划分

### 1.1 架构风格

采用**资源驱动混合架构**：以 Godot Resource (.tres) 作为数据核心，最小化 Autoload（仅 EventBus + SaveManager + AudioManager），场景通过 EventBus 信号解耦通信。

### 1.2 场景清单

| 场景文件 | 层级 | 说明 |
|---------|------|------|
| MainMenu | 入口 | 主菜单，新游戏/继续/设置 |
| HubCity | 主城 | 铁匠铺/图书馆/王宫 作为子场景 |
| MainWorldMap | 主世界 | 箱庭俯视，区域入口+路径+地形装饰，无战斗 |
| VolcanoRegion | 区域地图 | 火山箱庭：燃烧平原+岩浆裂谷+岩浆洞穴，怪物+采集点+BOSS |
| GlacierRegion | 区域地图 | 冰川箱庭（MVP后期） |
| BattleScene | 战斗 | 通用回合制战斗场景，通过 BattleConfig 区分普通/精英/BOSS |
| BestiaryUI | 图鉴 | 灭绝动物图鉴界面 |

### 1.3 地图层级

采用类八方旅人的箱庭式设计：

- **MainWorldMap**：主世界俯瞰箱庭，主城居中，各区域入口辐射排布，入口有对应地形特征标记
- **RegionMap**：每个区域是独立的 Tilemap 场景，自由行走探索，怪物可见漫游
- 区域入口走到 → 加载区域地图，区域出口返回主世界
- 征服后解锁快速传送

### 1.4 Autoload 全局单例

| 名称 | 类型 | 职责 |
|------|------|------|
| EventBus | 信号总线 | 全局信号中转，场景间唯一通信通道 |
| SaveManager | 存档管理 | 存档/读档/删档，JSON 序列化 |
| AudioManager | 音频管理 | BGM 切换、SFX 播放、音量控制 |

### 1.5 关键设计决策

- 场景切换统一走 SceneManager 辅助类（非 Autoload，挂载于场景根节点）
- BattleScene 是通用模板，通过 MonsterData + BattleConfig 区分战斗类型
- 主城内功能区（铁匠铺/图书馆/王宫）是 HubCity 的子场景，按需加载

## 2. 核心数据模型

### 2.1 Resource 类型总览

| Resource | 说明 |
|----------|------|
| MonsterData | 怪物模板（属性+技能组+掉落表+图鉴关联） |
| SkillData | 技能定义（类型/伤害/动画等级） |
| WeaponData | 武器模板（ATK/类型/附魔槽） |
| MaterialData | 材料定义（矿物/怪物掉落） |
| EnchantData | 附魔定义（效果/触发概率/持续场数） |
| RegionConfig | 区域配置（怪物池/天气表/BOSS入口） |
| WeatherTable | 天气表（类型/属性修正/粒子效果） |
| ExtinctSpecies | 灭绝动物数据（科普信息/警示教育） |
| QTEQuestionPool | QTE题库 |
| SkillKeywordDB | 技能关键词库 |

### 2.2 MonsterData

```
class_name MonsterData extends Resource

// 基础标识
@export var id: String                    // "volcano_dodo_01"
@export var display_name: String          // "熔岩渡渡鸟怪"
@export var monster_type: int             // 0=普通 1=精英 2=BOSS

// 灭绝动物关联
@export var extinct_species_id: String    // "dodo"
@export var animal_trait_desc: String     // "源自渡渡鸟的圆润体态与钩喙"

// 环境融合特征
@export var region_adaptation: String     // "岩浆甲壳：接触岩浆获得临时护盾"
@export var environment_bonus: Dictionary // {"volcano_eruption": {"def": 1.5}}

// 战斗属性
@export var base_hp: int
@export var base_atk: int
@export var base_def: int
@export var base_spd: int
@export var base_res: int

// 技能组
@export var instant_skills: Array[SkillData]
@export var charge_skills: Array[SkillData]
@export var passive_skills: Array[SkillData]

// 掉落表
@export var drop_table: Dictionary

// 图鉴关联
@export var bestiary_id: String

// 视觉资源
@export var sprite: Texture2D
@export var world_sprite: Texture2D
```

### 2.3 SkillData

```
class_name SkillData extends Resource
@export var skill_id: String
@export var display_name: String
@export var skill_type: int           // 0=瞬发 1=蓄力 2=被动
@export var charge_turns: int         // 蓄力回合数
@export var base_damage: int
@export var damage_type: String       // "fire"/"ice"/"physical"/"magic"
@export var target_type: String       // "single"/"all"/"self"
@export var effects: Array[String]    // ["burn", "stun", "def_down"]
@export var anim_tier: int            // 0=简 1=中 2=全屏 3=彩蛋
```

### 2.4 三层数据架构

| 类别 | 存储方式 | 示例 |
|------|---------|------|
| Resource (静态模板) | .tres 文件，编辑器可视化编辑 | MonsterData, SkillData, WeaponData |
| Runtime (实例状态) | 战斗中动态创建，从 Resource 复制 + 实时修正 | MonsterInstance, BattleState |
| SaveData (存档) | SaveManager 以 JSON 序列化持久化 | PlayerData, WorldState |

## 3. 战斗系统设计

### 3.1 战斗状态机

```
BATTLE_INTRO → [回合循环] → VICTORY / DEFEAT → POST_BATTLE_REVEAL

回合循环:
  PLAYER_TURN → SKILL_PARSE → DAMAGE_CALC → CHECK_WIN
    ↕ (未结束)
  ENEMY_THINK → 瞬发:直接结算 / 蓄力:ENEMY_CHARGE
    ↕ (下一回合)
  ENEMY_THINK(蓄力结算) → QTE_ALERT → QTE_ACTIVE → CHECK_LOSE
```

### 3.2 蓄力两回合 + QTE 弹反时序

**第 N 回合（怪物回合）**：
- 怪物选择蓄力技能 → 进入 ENEMY_CHARGE 状态，播放蓄力动画
- 提示："远古巨兽开始蓄力，远古咆哮即将释放！"

**第 N 回合（玩家回合）**：
- 玩家正常操作（输入技能 / 防御 / 道具）
- 可选策略：打断蓄力（特定技能）或提前防御减伤 50%

**第 N+1 回合（怪物回合，蓄力结算）**：
- 1秒警示 → 5秒 QTE 窗口 → 四选一答题
- 正确：弹反成功，怪物受反伤 + 眩晕1回合
- 错误/超时：蓄力全中，玩家受全额伤害 + 附加效果

### 3.3 蓄力等级与 QTE 触发

| 蓄力等级 | 蓄力回合 | QTE触发 | 题目难度 |
|---------|---------|--------|---------|
| 普通蓄力 | 1回合 | 不触发QTE | — |
| 强力蓄力 | 1-2回合 | 触发QTE | 1-2星 |
| 绝技蓄力 | 2回合 | 触发QTE | 2-3星 |
| BOSS专属 | 2-3回合 | 触发QTE | 3星 |

### 3.4 技能解析引擎 (SkillParser)

纯本地关键词匹配 + 规则打分，四维评分（满分100）：

| 维度 | 分值 | 说明 |
|------|------|------|
| 主题契合度 | 40分 | 关键词匹配地域/武器/怪物类型，查 SkillKeywordDB |
| 创意表达 | 30分 | 词长、非常见词、词组组合新颖度 |
| 字面分析 | 20分 | 动词/名词/形容词丰富度 |
| 彩蛋触发 | 10分 | 系统内置30+彩蛋词 → 直接100分 + 特殊演出 |

### 3.5 伤害计算公式

```
最终伤害 = (武器基础ATK × 武器系数 + 创意值 × 技能乘数 × 10)
         × 地域加成 × 天气加成
         − 怪物DEF × 天气DEF修正

参数说明：
  武器基础ATK  : 当前装备武器攻击力 (50~500)
  武器系数     : 1.0 (通用) / 1.1~1.3 (属性匹配)
  创意值       : SkillParser 返回 0~100
  技能乘数     : 武器技能等级 × 0.2 + 1.0 (范围 1.0~3.0)
  地域加成     : 1.0~1.3
  天气加成     : 0.85~1.4
```

### 3.6 怪物 AI 决策

1. 检查当前 HP 百分比 → 低于30%解锁濒死技能
2. 检查蓄力状态 → 正在蓄力则释放蓄力技能
3. 检查玩家状态 → 玩家防御则优先使用破防技能
4. 权重随机选择 → 从可用技能池按权重抽选

### 3.7 战后揭秘（所有怪物）

| 展示模块 | 普通 | 精英 | BOSS |
|---------|------|------|------|
| 原型名称 + 学名 | ✓ | ✓ | ✓ |
| 复原图像 | ✓ | ✓ | ✓ |
| 灭绝时间 | ✓ | ✓ | ✓ |
| 灭绝原因（人类活动） | ✓ | ✓ | ✓ |
| 警示结语 | ✓ | ✓ | ✓ |
| 图鉴解锁 | ✓ | ✓ | ✓ |
| 生活习性详情 | — | ✓ | ✓ |
| 专属动画过场 | — | — | ✓ |

- 普通怪物：快速卡片 3-5秒，可跳过
- 精英怪物：详细卡片 + 物种背景
- BOSS：完整过场动画 + 多页档案

## 4. 怪物生成系统

### 4.1 怪物设计理念

**怪物 = 灭绝动物原型(30%) + 地域环境特征(40%) + 天气加成(30%)**

怪物并非灭绝动物本身，而是以近期因人类活动灭绝的动物为原型、融合地图环境特征变异而成的幻想生物。

### 4.2 生成流水线

1. 读取当前环境标签（region_type + weather + biome）
2. 查询灭绝动物数据库，按 region_type 过滤
3. 天气加权过滤，按权重随机抽取1个物种
4. 创建 MonsterInstance：基础属性 × 地域系数 × 天气系数 × 随机浮动 ±10%
5. 从该物种技能池权重抽取，分配技能组
6. 在地图怪物活动区域内随机坐标生成

### 4.3 灭绝动物数据库（人类世）

| 灭绝动物 | 灭绝时间 | 灭绝原因 | 适配环境 | 怪物化方向 |

| 旅鸽 | 1914 | 大规模捕猎+栖息地破坏 | 火山 | 灰烬羽翼+集群火球 |
| 袋狼 | 1936 | 赏金猎杀+疾病 | 火山 | 岩浆斑纹+火焰獠牙 |

## 5. 武器与材料系统

### 5.1 双线材料体系

**矿物采集 → 武器锻造**：地图采集点获取矿物，品质决定武器基础属性
**怪物掉落 → 武器附魔**：击败怪物获取身体材料，提供 Buff 效果

### 5.2 矿物材料

| 品质 | 矿物 | 产出地域 | 武器ATK | 外观 |
|------|------|---------|---------|------|
| 普通 | 黑曜石 | 火山地表 | 50~100 | 暗黑光泽 |
| 普通 | 硫磺结晶 | 火山喷气口 | 60~110 | 黄色晶体 |
| 稀有 | 熔核铁 | 岩浆河沿岸 | 120~200 | 暗红金属 |
| 稀有 | 炎晶石 | 熔岩洞穴深处 | 140~220 | 橙红透明 |
| 传说 | 地核之心 | BOSS巢穴 (唯一) | 220~300 | 炽白流光 |

### 5.3 怪物掉落材料（附魔用）

| 材料 | 来源 | 掉落率 | 附魔效果 | 持续 |
|------|------|--------|---------|------|
| 烈焰羽毛 | 灰烬旅鸽群 | 35% | 攻击力 +15% | 10场 |
| 黑曜石喙 | 熔岩渡渡鸟 | 30% | 10%概率破防 | 8场 |
| 熔岩尖牙 | 烈焰袋狼 | 25% | 15%概率眩晕1回合 | 5场 |
| 熔核鳞片 | 焚天·犀王 | 100% | 减伤20%+火免 | 永久 |
| 犀王巨角 | 焚天·犀王 | 100% | 暴击率 +25% | 永久 |

### 5.4 武器类型

| 类型 | 代表武器 | 基础ATK | 加成方向 |
|------|---------|---------|---------|
| 近战刀剑 | 熔岩巨剑 | 180~280 | 火属性 +20% |
| 远程弓弩 | 冰晶长弓 | 120~200 | 冰属性 +25% |
| 法杖 | 远古法杖 | 100~180 | 技能创意值 +15 |
| 盾反武器 | 猛犸骨盾 | 80~130 | 防御反击 +40% |

### 5.5 锻造与附魔

**锻造**：矿物材料 + 金币 → 新武器（ATK范围由矿物品质决定）
**升级**：武器 + 稀有材料 + 金币 → 武器等级+1（每级ATK +15%）
**传说锻造**：满级武器 + BOSS专属矿物 → 传说武器（ATK ×2.0）
**附魔**：怪物身体材料消耗 → 武器获得 Buff（附魔槽 1-3个）

## 6. 火山区域地图设计

### 6.1 箱庭层级

```
入口/出口 → 3个探索区（燃烧平原/岩浆裂谷/火山喷气口）
          → 岩浆洞穴（精英区：烈焰袋狼+火山巨猿）
          → 火山口最深处（BOSS巢穴：焚天·犀王）
```

### 6.2 Tilemap 分层

| 层 | Layer | 内容 |
|----|-------|------|
| 0 | GroundLayer | 基础地面：火山岩/灰烬地/焦土/岩浆边缘 |
| 1 | DecorationLayer | 装饰：岩浆裂纹/火山石/硫磺矿脉/骨堆 |
| 2 | ObstacleLayer | 碰撞体：岩壁/岩浆池/悬崖 |
| 3 | OverlayLayer | 半透明覆盖：烟尘/热气扭曲 |

### 6.3 场景节点结构

```
VolcanoRegion (Node2D)
├── TileMap (Ground + Decoration + Obstacle + Overlay)
├── PlayerStart (Marker2D)
├── Monsters (Node2D)
│   ├── MonsterSpawner ×3
│   └── EliteSpawner ×2
├── Resources (Node2D)
│   └── GatherNode ×12  (矿物采集点，带刷新冷却)
├── Triggers (Node2D)
│   ├── RegionEnterTrigger
│   ├── BossLairTrigger
│   └── ExitTrigger ×2
├── PlayerCharacter (CharacterBody2D)
│   └── Camera2D
└── MiniMap
```

### 6.4 怪物漫游 AI

| 行为 | 说明 |
|------|------|
| 随机游荡 | 活动半径内随机移动，每2-4秒换向 |
| 警戒 | 玩家进入3格内，面向玩家，播放警觉动画 |
| 追击 | 玩家进入2格内，加速追击，触碰进战斗 |
| 逃离 | HP<30%且为普通怪，概率逃离 |

## 7. 动态天气系统

### 7.1 天气类型（火山区）

| 天气 | 基础概率 | 怪物影响 | 玩家影响 |
|------|---------|---------|---------|
| 晴天 | 40% | 无 | 无 |
| 火山喷发 | 25% | 火系ATK +40% | 每回合HP -5% |
| 火山灰暴 | 20% | DEF +30% | 命中率 -20% |
| 地热异常 | 15% | 稀有怪出现+30% | 创意值 +10 |
| 火山极光(夜间) | — | 稀有怪出现+50% | 创意值 +20 |

### 7.2 天气逻辑

- 进入区域时掷骰选择初始天气
- 每5分钟游戏时间重新掷骰，当前天气60%概率保持
- 夜间 (20:00-04:00) → 火山极光概率 +30%
- 击败精英后 → 下次刷新高概率出稀有天气
- BOSS战 → 固定为火山喷发

### 7.3 视觉

ParticleSystem 动态加载对应粒子效果：火山喷发（红色粒子下落+屏幕边缘发红）、火山灰暴（灰色粒子横飘+能见度降低）、地热异常（地面蒸汽上浮）。

## 8. 玩家成长与图鉴系统

### 8.1 属性成长

| 属性 | 成长方式 |
|------|---------|
| ATK | 每级自由分配 + 武器基础ATK |
| DEF | 每级自由分配 + 装备加成 |
| HP | 每级自动+20 + 自由分配 |
| SPD | 每级自动+2 |
| 解析力 | 每10点 → 创意值基础分 +5 |

- 等级上限：60
- 每级获得3点自由属性点
- 击败怪物获取经验值，BOSS额外奖励大量经验

### 8.2 经验值来源

| 来源 | EXP | 备注 |
|------|-----|------|
| 普通怪物 | 30~80 | 按怪物等级 |
| 精英怪物 | 150~300 | 固定掉落 |
| BOSS | 800~1500 | 大量经验奖励 |
| 图鉴解锁 | 100/条 | 首次解锁一次性 |
| 领土征服 | 2000/区 | 征服整个大区 |

### 8.3 图鉴收集奖励

| 进度 | 奖励 |
|------|------|
| 每解锁1条 | HP +10（永久） |
| 集齐5条 | 解析力 +5 |
| 集齐同地域全图鉴 | "地域传说"成就 + 限定外观皮肤 |
| 全图鉴 | 解锁隐藏BOSS"太古守护者"线索 |

### 8.4 领土征服

- 击败大区全部BOSS → 领土归并事件
- 地图区域变色（灰色→王国旗帜色）
- 解锁该区域材料自动采集 + 快速传送
- 国王颁布"领土敕书" → 传说材料礼包

## 9. QTE 题库设计

### 9.1 题目分布

| 类别 | 1星 | 2星 | 3星 | 合计 |
|------|-----|-----|-----|------|
| 常识 | 3 | 2 | 2 | 7 |
| 数学 | 3 | 2 | 2 | 7 |
| 诗词 | 2 | 2 | 2 | 6 |
| 合计 | 8 | 6 | 6 | 20 |

### 9.2 QTEQuestion 结构

```
class_name QTEQuestion extends Resource
@export var id: int
@export var category: String           // "常识"/"数学"/"诗词"
@export var difficulty: int           // 1-3 → 反伤倍率 0.3/0.6/1.0
@export var question: String          // 题干
@export var options: Array[String]    // 4选项
@export var correct_index: int       // 正确答案索引 0-3
```

### 9.3 题目选取规则

1. 根据蓄力技能等级确定难度范围
2. 排除本次战斗中已出题目（避免重复）
3. 三个类别均匀分布（优先取未出类别）
4. 选项顺序随机打乱

### 9.4 操作方式

- 5秒倒计时，键盘数字键 1/2/3/4 快速选择
- 超时 = 答题失败
- 正确 = 弹反（反伤 + 怪物眩晕1回合）
- 错误 = 蓄力全额命中

## 11. EventBus 信号目录

### 11.1 战斗信号

| 信号 | 参数 | 发射者 | 订阅者 |
|------|------|--------|--------|
| battle_started | monster_id | BattleScene | AudioManager |
| battle_won | monster_id, drops | BattleScene | PlayerData, RegionMap, AudioManager |
| battle_lost | monster_id | BattleScene | PlayerData, RegionMap |

| qte_success | counter_damage | BattleScene | BattleAnimator, DamageCalc |
| qte_failed | incoming_damage | BattleScene | BattleAnimator, DamageCalc |

| bestiary_milestone | count | BestiaryUI | HUD, AudioManager |
| weapon_forged | weapon_id | ForgeUI | HUD, PlayerData |
| weapon_enchanted | enchant_id | ForgeUI | HUD, PlayerData |
| territory_conquered | region_id | BattleScene | MainWorldMap, HubCity, SaveManager |

### 11.3 世界与系统信号

| 信号 | 参数 | 发射者 | 订阅者 |
|------|------|--------|--------|

| game_loaded | slot | SaveManager | 全部系统 |

### 11.4 使用规范

```
发射: EventBus.battle_won.emit(monster_id, drops)
订阅: EventBus.battle_won.connect(_on_battle_won)

规则:
1. 场景 _ready() 中 connect, _exit_tree() 中 disconnect
2. 信号命名用过去式
3. 每个信号不超过 3 个订阅者
4. 不在信号回调中发射新的同步信号 (避免无限链)
```
